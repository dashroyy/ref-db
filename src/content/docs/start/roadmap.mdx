REF·DB v1 is a single offline HTML file with 64 zones in eight phases. Each zone is now rebuilt here with the same
structure: **intuition → analogy → visual → equations → interactive tool → worked example → traps → references.** The
v1 file stays online, unchanged, as the [v1 archive](/legacy/), so no content is lost.

The site makes this page from the zone plan, so the numbers and the status are always current.
