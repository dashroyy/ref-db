# Build log

Each file in this folder is one entry in the build log on /lab/, newest first by `date`.
Copy an existing entry, rename it (the name doesn't show anywhere), and fill it in:

```
---
date: 2026-11          # year-month (or a full date: 2026-11-14)
title: Pen Launcher v3
example: false         # true marks it as a placeholder (shown with an "Example" badge)
photos: [v3-side.jpg, v3-launch.jpg]   # optional: files in src/photos/build-log/
---

What changed and why, in a few sentences. Blank lines start new paragraphs.
```

Delete the three example entries once you have real ones. Customer commissions only with the
customer's OK.
